# 기술적분석투자

세 명의 기술적 분석 전문가의 방식으로 종목과 시장을 판정하고, 세 방식이 함께 추천하는 종목을 보여 주는 웹앱입니다. 파일 하나(`index.html`)로 동작하며 별도 서버 없이 GitHub Pages에서 쓸 수 있습니다.

| 전문가 | 방식 |
| --- | --- |
| 스탠 와인스타인 | 30주 이동평균으로 보는 4단계 주기, 2단계 초입 돌파 매수 |
| 윌리엄 오닐 | CAN SLIM, 컵·핸들과 플랫 베이스 돌파, 7~8% 손절 |
| 마크 미너비니 | 트렌드 템플릿 8개 조건, 변동성 수축(VCP) 피벗 돌파 |

## 화면 구성

맨 위에 앱 이름이 있고 오른쪽 끝에 설정(톱니바퀴) 아이콘이 있으며, 큰 탭 4개로 나뉩니다.

- **종합**: 앱을 열면 가장 먼저 나옵니다.
  - 세 전문가가 모두 매수권·관심·보유로 보는 공동 추천 종목을 이유와 함께 보여 줍니다. 두 전문가 추천과 방식별 상위 10개도 있습니다.
  - 종목 추가와 코드로 일괄 추가는 여기에서만 합니다. 여기서 추가한 종목은 세 방식 목록에 모두 들어갑니다.
  - 세 방식의 시장 판정과 전체 시장 스캔이 있습니다.
- **와인스타인 / 오닐 / 미너비니**: 각 방식의 종목, 시장, 규칙 탭이 있고 종목 목록은 전문가마다 따로입니다. 와인스타인에는 후보 탭이 더 있습니다.
- **설정(⚙)**: 오른쪽 위 톱니바퀴를 누르면 열립니다. 안에 시세 서버 연결(세 방식이 함께 씁니다)과 백업/복원이 있습니다.

## 판정 방식

### 와인스타인
- 종목과 시장을 1단계(바닥), 2단계(상승), 3단계(천장), 4단계(하락)로 판정합니다.
- 신호: 매수 적기, 돌파 대기, 보유, 과열, 비중 축소, 매수 금지
- 매수 체크리스트 8항목: 2단계, 30주선 우상향, 저항선 돌파, 돌파 거래량, 상대강도, 위쪽 매물대, 시장 지수, 과열 여부

### 오닐
- 기준: 시장 대비 강세(L), 52주 신고가 근접(N), 상승 추세, 컵·핸들·플랫 베이스, 매집, 돌파 거래량, 시장 방향(M)
- 매수 지점에서 5%를 넘으면 추격하지 않고, 손절은 매수가 −8%, 1차 목표는 +20%입니다.
- 시장은 상승장 확인, 상승 압력 약화, 조정장으로 판정합니다.
- 분기·연간 실적(C·A)은 가격 데이터로 알 수 없어 확인불가로 표시합니다.

### 미너비니
- 트렌드 템플릿: 주가 > 30주선·40주선, 30주선 > 40주선, 40주선 상승, 10·30·40주선 정배열, 주가 > 10주선, 52주 저점 +30% 이상, 고점 −25% 이내, 상대강도
- 변동성 수축(VCP)이 있고 피벗을 거래량과 함께 넘으면 매수 적기입니다.
- 손절은 −8% 또는 마지막 수축 저점 아래이며, 1차 목표는 +20%입니다.
- 시장은 지수가 트렌드 템플릿 7개 조건을 몇 개 충족하는지로 판정합니다.
- 상대강도는 전체 종목 순위 대신 시장 대비 52주 수익률로 대체했습니다.

### 공동 추천
와인스타인은 2단계 종목이고 오닐과 미너비니는 매수 적기·관심·보유 중 하나일 때, 세 방식이 모두 긍정한 종목으로 봅니다. 매수 적기·관심이 많은 순으로 보여 줍니다.

## 사용법

1. 설정(⚙)의 연결에서 시세 서버를 연결합니다(아래 참고).
2. 종합 탭의 종목 추가에 종목명을 입력하면 종목코드가 자동으로 채워집니다. 코드로 일괄 추가에는 6자리 코드를 여러 개 넣을 수 있습니다.
3. 일봉 또는 주봉 표(날짜, 종가, 거래량)를 직접 붙여넣을 수도 있습니다. 일봉은 주봉으로 자동 변환되고, 최소 52주(권장 60주 이상)가 필요합니다.
4. 각 전문가 탭의 종목 정리(삭제)로 지우거나 전체 새로고침으로 시세를 다시 받습니다.

데이터는 브라우저(localStorage)에만 저장됩니다. 기기를 옮길 때는 설정(⚙)의 백업/복원을 사용하세요.

## 시세 서버 연결 (KIS 프록시)

기존 KIS 프록시의 `/stock-history/:code?period=W` 경로에서 주봉을 받아옵니다. GitHub Pages처럼 직접 올린 주소에서만 동작합니다.

1. 설정(⚙)의 연결에서 프록시 주소와 서버 비밀키를 입력하고 저장하고 연결 테스트를 누릅니다. 비밀키를 보내는 방식은 테스트가 자동으로 찾아 저장합니다.
2. 시장 지수는 지수를 따라가는 ETF(기본 069500, KODEX 200)로 대신합니다. 코스닥 위주라면 229200으로 바꿀 수 있습니다.
3. 앱을 열 때 시장 지수가 자동으로 새로 고쳐집니다. 개별주 자동 새로고침은 설정(⚙)의 연결에서 켤 수 있고, 기본은 끔입니다.

비밀키는 이 브라우저에만 저장되며 백업 텍스트에는 포함되지 않습니다.

## 전체 시장 스캔

종합 탭의 전체 시장 스캔은 종목 목록의 종목을 하나씩 서버에서 받아 세 방식으로 판정합니다.

- 끝나면 각 방식의 상위 종목이 해당 전문가 목록에 자동으로 들어갑니다. 와인스타인은 단계별 10개, 오닐과 미너비니는 상위 10개입니다.
- 종목 목록이 없으면 앱에 내장된 약 190종목을 스캔합니다.
- 코스피·코스닥 전체를 스캔하려면 설정(⚙)의 연결의 전체 종목 목록에 종목코드를 붙여넣으세요. 한 줄에 코드 하나나 "이름,코드" 형식이고, 우선주는 자동으로 제외됩니다. 자동으로 받기 버튼도 있지만 브라우저가 막으면 실패합니다.
- 전체를 스캔하면 10분 넘게 걸릴 수 있습니다. 중단했다가 이어서 스캔할 수 있습니다.

## GitHub Pages로 배포

1. GitHub에서 새 저장소를 만듭니다. 이름 예: `stage-analyzer`
2. Add file → Upload files로 `index.html`, `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `README.md`를 모두 올리고 Commit합니다.
3. Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save합니다.
4. 1~2분 뒤 `https://<사용자명>.github.io/stage-analyzer/` 주소로 열립니다.

아이폰에서는 Safari로 열고 공유 → 홈 화면에 추가를 하면 앱처럼 쓸 수 있습니다. 앱 이름이 바뀌었거나 아이콘이 갱신되지 않으면 홈 화면에서 지우고 다시 추가하세요.

## 판정 기준값

`index.html` 안의 상수로 조정합니다.

| 상수 | 기본값 | 의미 |
| --- | --- | --- |
| `FLAT` | 1.5 | 30주선이 평평하다고 보는 10주 변화율(±%) |
| `BRK_MIN` | 1.02 | 직전 26주 최고 종가 대비 돌파로 인정하는 배율 |
| `VOL_X` | 2 | 와인스타인 돌파 거래량 기준 (직전 4주 평균 대비 배수) |
| `EXT_OK` | 15 | 30주선 이격이 적정한 한계(%) |
| `EXT_HOT` | 30 | 과열로 보는 이격(%) |

오닐·미너비니의 기준값(거래량 140%, 매수 구간 +5%, 손절 −8% 등)은 `analyzeONeil`, `analyzeMinervini` 함수 안에 있습니다.

## 주의

각 전문가의 규칙을 가격·거래량으로 판정할 수 있는 부분만 기계적으로 옮긴 참고용 도구입니다. 패턴 인식은 주봉 가격으로 근사한 것이고 실적은 반영하지 않습니다. 판정이 차트의 인상과 다르면 차트를 우선하세요. 투자 판단과 책임은 본인에게 있습니다.
