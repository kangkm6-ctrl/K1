# 스테이지 분석기

스탠 와인스타인의 《주식투자 최적의 타이밍을 잡는 법》 방식을 따라, 30주 이동평균으로 종목과 시장의 4단계(바닥·상승·천장·하락)를 판정하는 웹앱입니다. 파일 하나(`index.html`)로 동작하며 서버가 필요 없습니다.

## 기능

- 종목별 1~4단계 판정과 신호 (매수 적기, 돌파 대기, 보유, 비중 축소, 매수 금지)
- 주봉 차트: 가격, 30주선, 거래량, 단계별 배경색, 돌파 표시
- 매수 체크리스트 8항목: 2단계, 30주선 우상향, 저항선 돌파, 돌파 거래량, 상대강도, 위쪽 매물대, 시장 지수, 과열 여부
- 시장 지수 단계 판정 (하락 단계에서는 매수 신호 차단)
- 손절 기준가와 허용 손실 기준 매수 수량 계산

## 사용법

1. 증권사나 야후 파이낸스에서 일봉 또는 주봉 표를 복사합니다. 날짜와 종가 열이 필요하고, 거래량·고가·저가가 있으면 함께 씁니다.
2. 앱의 종목 추가에 붙여넣고 저장합니다. 일봉은 주봉으로 자동 변환됩니다.
3. 최소 40주, 권장 60주 이상의 데이터가 필요합니다.
4. 시장 탭에 코스피 같은 지수를 등록하면 상대강도와 시장 단계가 종목 판정에 반영됩니다.

데이터는 브라우저(localStorage)에만 저장됩니다. 기기를 옮길 때는 종목 탭 맨 아래 백업과 복원을 사용하세요.

## GitHub Pages로 배포

1. GitHub에서 새 저장소를 만듭니다. 이름 예: `stage-analyzer`
2. Add file → Upload files로 `index.html`, `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `README.md`를 모두 올리고 Commit합니다.
3. Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 선택하고 Save합니다.
4. 1~2분 뒤 `https://<사용자명>.github.io/stage-analyzer/` 주소로 열립니다.

아이폰에서는 Safari로 열고 공유 → 홈 화면에 추가를 하면 앱처럼 쓸 수 있습니다.

## 판정 기준값

`index.html` 안의 `FLAT`, `EXT_OK`, `EXT_HOT`, `BRK_MIN`, `VOL_X` 상수로 조정합니다.

| 상수 | 기본값 | 의미 |
| --- | --- | --- |
| `FLAT` | 1.5 | 30주선이 평평하다고 보는 10주 변화율(±%) |
| `BRK_MIN` | 1.02 | 직전 26주 최고 종가 대비 돌파로 인정하는 배율 |
| `VOL_X` | 2 | 돌파 거래량 기준 (직전 4주 평균 대비 배수) |
| `EXT_OK` | 15 | 30주선 이격이 적정한 한계(%) |
| `EXT_HOT` | 30 | 과열로 보는 이격(%) |
